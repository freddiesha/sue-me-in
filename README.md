# Sue Me, Inc.

A Windows 2000-style law firm tycoon game. You play a junior partner who quits Hartwell, Pike & Lowe to start your own firm in a basement office.

The whole game is one HTML file in `public/index.html`. It has no build step and no dependencies, and it saves your progress in the browser.

## Play locally

Open `public/index.html` in a browser.

## Deploy on Render

This repo includes a `render.yaml` Blueprint that sets it up as a free static site.

1. In the Render dashboard, choose **New > Blueprint**.
2. Connect this GitHub repo and click **Apply**.

Render redeploys automatically each time you push to `main`.

## Add it to your iPhone home screen

Open the site in Safari, tap the Share button, then **Add to Home Screen**. It opens full screen like an app.
